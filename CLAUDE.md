# CLAUDE.md — Guidelines for AI-assisted contribution to C4-Auto

## Naming conventions

This project uses C++-influenced naming that differs from idiomatic TypeScript defaults. Follow these conventions in all new code:

- **Enum types** — prefix with `E` (e.g. `ETimeWindow`, `EC4DiagramType`, `EVisitorPriority`).
- **Interface types** — prefix with `I` (e.g. `IFileReader`, `IDocGenOptions`, `IDirectoryVisitor`).
- **Enum values** — prefix with `k` (e.g. `kOneWeek`, `kComponent`, `kFirst`). These are string-valued enums; the value equals the name (e.g. `kOneWeek = 'kOneWeek'`).

## Error handling

Use error classes from `@jonverrier/prompt-repository`:
- `InvalidParameterError` — bad user input or CLI arguments.
- `InvalidOperationError` — runtime logic failures (missing prompt, parse failure).
- `ConnectionError` — API/network failures.

Do **not** use `new Error(...)` directly.

## Dependency injection

All I/O and LLM interactions are abstracted behind interfaces (`IFileReader`, `IFileWriter`, `IChatDriver`, `IPromptRepository`) so unit tests can inject mocks. Production wiring lives in `VisitorFactory.ts`.

## Prompt IDs

LLM prompt identifiers live in `src/PromptIds.ts`. The matching prompt definitions are in `src/Prompts.json`. The two files must be updated in lockstep — never change an ID in one without changing it in the other.

Prompt IDs must be valid UUIDs (hex digits `0–9`, `a–f` only; no `g`–`z`).

## Shared utilities

Date formatting and time-window constants are in `src/DateUtils.ts`. Import from there — do not redeclare `formatDateYYYYMMDD`, `parseDateYYYYMMDD`, `MS_PER_DAY`, or `TIME_WINDOW_DAYS` in other modules.

## StrongAI sentinels

Generated header blocks use the markers:
```
// ===Start StrongAI Generated Comment (YYYYMMDD)===
// ...
// ===End StrongAI Generated Comment===
```
and generated README files open with:
```
<!-- Generated by StrongAIAutoDoc YYYYMMDD -->
```
Do not change these sentinel strings — they are used for staleness detection.

## LLM model

The tool uses `EModel.kLarge` / `EModelProvider.kOpenAI` (maps to **gpt-4o**) for all LLM calls. Change this only if the underlying model mapping in `@jonverrier/prompt-repository` changes.

## Testing

- `npm test` — unit + integration tests (no API key required).
- `npm run test:e2e` — end-to-end tests (requires `OPENAI_API_KEY`).

All new visitors or utilities must have unit test coverage. Tests live in `test/`.
